# FocusList - Midnight Glass

Functional To-Do app with priority, search, filters, stats and localStorage.

**Live:** https://lishakashy2008-cloud.github.io/focuslist-midnight/
**Stack:** HTML5, CSS3, Vanilla JS

Features:
- Add / Edit / Delete / Complete tasks
- Priority levels (High/Med/Low) with colors
- Search + All/Active/Completed + Priority filter
- Stats - Total / Completed / Pending
- localStorage persistence
- Responsive, ARIA labels, Keyboard (Enter to add)

Run: Just open index.html
